ส่องหินอัคนี AR — วิธีนำขึ้นเว็บให้นักเรียนใช้ AR บนมือถือ
=========================================================

ไฟล์ในชุดนี้
  index.html      หน้าเว็บ (ภาษาไทย หมุดป้ายแร่ ปุ่ม AR รายการหิน 12 ก้อน)
  scans/*.glb     โมเดลหิน 12 ก้อน (ลดขนาดแล้ว รวมประมาณ 26 MB)
  .nojekyll       ไฟล์ว่างสำหรับ GitHub Pages

ฝากเว็บฟรีด้วย GitHub Pages
  1. สมัคร/เข้าสู่ระบบ github.com แล้วกด New repository ตั้งชื่อ เช่น rock-ar เลือก Public
  2. กด "uploading an existing file" ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ scans) ขึ้นไป แล้วกด Commit
  3. ไปที่ Settings > Pages > Branch เลือก main และ / (root) แล้วกด Save
  4. รอ 1–2 นาที จะได้ลิงก์ https://ชื่อผู้ใช้.github.io/rock-ar/

ทำ QR ให้นักเรียน
  เปิดลิงก์ข้างต้นในคอมพิวเตอร์ กดปุ่ม "QR สำหรับนักเรียน" หน้าเว็บจะสร้าง QR ของหินทั้ง 12 ก้อน
  (ลิงก์ลงท้ายด้วย #granite, #basalt ... จะเปิดที่หินก้อนนั้นทันที) ถ่ายภาพหน้าจอแล้วพิมพ์ติดกับตัวอย่างหินจริงได้

อุปกรณ์ที่ใช้ AR ได้
  Android: Chrome บนเครื่องที่รองรับ Google Play Services for AR (ARCore)
  iPhone/iPad: Safari (ใช้ AR Quick Look ของ iOS)
  คอมพิวเตอร์: หมุนดู 3 มิติได้ แต่ไม่มีปุ่ม AR

ปรับตำแหน่งป้ายแร่
  กด "ครู: ปรับตำแหน่งป้าย" > "ย้าย" ที่ป้าย > แตะบนก้อนหินตรงจุดใหม่
  ตำแหน่งใหม่จำไว้เฉพาะเบราว์เซอร์นั้น ถ้าต้องการให้ทุกเครื่องเห็น กด "คัดลอกพิกัด"
  แล้วนำข้อความไปแทนข้อมูลของหินก้อนนั้นในตัวแปร HSPOS ใน index.html
