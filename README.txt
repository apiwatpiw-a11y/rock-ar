ส่องหิน 3 มิติและ AR — วิธีนำขึ้นเว็บให้นักเรียนใช้ AR บนมือถือ
=================================================================

ไฟล์ในชุดนี้
  index.html      หน้าเว็บ (แท็บหินอัคนี 12 / หินตะกอน 13 / หินแปร 10 ก้อน, หมุดป้าย, ปุ่ม AR, QR)
  scans/*.glb     โมเดลหิน 35 ไฟล์
  .nojekyll       ไฟล์ว่างสำหรับ GitHub Pages

อัปโหลดขึ้น GitHub Pages
  1. ไฟล์ index.html, README.txt, .nojekyll อัปโหลดที่หน้าหลักของ repository
  2. ไฟล์โมเดล .glb ต้องอยู่ในโฟลเดอร์ scans: เปิดลิงก์
       https://github.com/ชื่อผู้ใช้/rock-ar/upload/main/scans
     แล้วเลือกไฟล์ .glb ทั้งหมดลากลงไป (เลือกตัวไฟล์ ไม่ใช่ตัวโฟลเดอร์) กด Commit changes
     (หน้าอัปโหลดของ GitHub รับได้ครั้งละไม่เกิน 100 ไฟล์ ไฟล์ละไม่เกิน 25 MB)
  3. Settings > Pages > Branch: main / (root) > Save แล้วรอ 1–2 นาที

ทำ QR ให้นักเรียน
  เปิดหน้าเว็บในคอมพิวเตอร์ กด "QR สำหรับนักเรียน" จะได้ QR ทุกก้อนแยกตามกลุ่มหิน
  ลิงก์ลงท้ายด้วย #ชื่อหิน เช่น #granite #sandstone #schist จะเปิดที่หินก้อนนั้นทันที

อุปกรณ์ที่ใช้ AR ได้
  Android: Chrome บนเครื่องที่รองรับ Google Play Services for AR (ARCore)
  iPhone/iPad: Safari
  คอมพิวเตอร์: หมุนดู 3 มิติได้ แต่ไม่มีปุ่ม AR

ปรับตำแหน่งป้าย
  กด "ครู: ปรับตำแหน่งป้าย" > "ย้าย" > แตะบนก้อนหินตรงจุดใหม่ (จำไว้เฉพาะเบราว์เซอร์นั้น)
  กด "คัดลอกพิกัด" แล้วนำไปแทนข้อมูลในตัวแปร HSPOS ใน index.html ถ้าต้องการให้ทุกเครื่องเห็น
